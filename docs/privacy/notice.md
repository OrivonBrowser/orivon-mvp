# Privacy notice

Orivon sends usage statistics only after you turn them on, and you can turn them off or delete what was sent at any time in Settings.

## What telemetry sends

Every field of every report, exactly as it travels.

| Field | Meaning |
|---|---|
| `schema` | The version of the report format, always 2. |
| `installId` | An anonymous ID made from your computer's identifier. It cannot be turned back into the identifier. |
| `stream` | A random number for this profile, so two profiles open at once both count. |
| `region` | EU, US or other, from your time zone. |
| `version` | The Orivon version. |
| `period` | The month, as YYYY-MM. |
| `activeSec` | Seconds Orivon was in front and in use this month so far. |
| `backgroundSec` | Seconds Orivon was open but not in use this month so far. |
| `classes.web3` | Active seconds on Web3 sites. |
| `classes.web25` | Active seconds on Web2.5 sites. |
| `classes.web2` | Active seconds on Web2 sites. |
| `reportId` | A random number that names one month's sites report and links to nothing else. |
| `sites` | Seconds on each named Web3 or Web2.5 site this month so far; Web2 sites are never named. |
