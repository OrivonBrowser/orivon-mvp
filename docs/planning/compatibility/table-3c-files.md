# Table 3c: files (`fs`, `path`, `os`)

One part of the [compatibility matrix](../compatibility-matrix.md), which holds the legend, the
definition of every column and the index of all tables. This page says what works today and
nothing else.

The universe is Node 24's `fs` (104 keys), `fs.promises` (33), the `FileHandle` prototype (20 members and `close`), `Stats` (25 members), `Dirent` (9), `Dir` (8), the stream and watcher classes, `fs.constants` (56 keys), `path` (17 members, each again on `posix` and `win32`) and `os` (23 members, among them `os.constants` with 5 members). The file API under it is [`orivon.fs`](../../../src/contracts/capability-api.ts), which [Table 1a](table-1-capabilities.md) lists; every path is relative to one root per origin, shown to the app as `/orivon/app`. Of the 104 `fs` keys, 44 are present (21 callback functions, 21 `*Sync` functions, `constants`, `promises`), 58 refuse by name on both import forms, and `lchmod` and `lchmodSync` refuse by name on the default export but read `undefined` as named imports.
